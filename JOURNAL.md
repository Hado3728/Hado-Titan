## SEPTEMBER 09 : THIS SHOULD BE FUN

Today i spoke with my dad again and he gave some ideas on how to reduce the costs significantly. So I apparently got excited with learning solidworks that i have spammed the fillet feature which is gonna cost a lot more and extra, so.... today i worked on removing em and make some changes in order to make it more workable and easy so the price is reduced. As per what i learnt about UHMWPE it actually is really good for impact but i can't put screws in it, it gets expanded and the screws come loose, so imma use aluminium casing with 3mm thickness.
